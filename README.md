# 🚀 Проекты

## 01. Автоматизация расчёта индивидуальных планов продаж

Разработка автоматизированной SQL-модели для ежемесячного расчёта индивидуальных планов продаж для **300–400 сотрудников**.

### Задача

Изначально расчёт выполнялся в Excel и занимал около **15–20 часов ежемесячно**.

Необходимо было автоматизировать расчёт с учётом большого количества изменяющихся факторов:

- кадровых изменений;
- периодов отсутствия сотрудников;
- отпусков, больничных и других типов отсутствия;
- производственного календаря;
- количества рабочих дней;
- коэффициентов;
- организационных параметров;
- изменений руководящих позиций.

### Решение

Расчётная модель была перенесена из Excel в **SQL Server / T-SQL**.

К модели подключены автоматизированные кадровые данные по сотрудникам и периодам отсутствия.

В рабочем решении используются **7 параметрических справочников** с коэффициентами и другими изменяемыми параметрами. Бизнес-параметры отделены от основной SQL-логики, поэтому изменение коэффициентов и значений не требует изменения расчётного SQL-кода.

Реализован учёт производственного календаря и периодов отсутствия. Периоды, переходящие между месяцами, распределяются по соответствующим расчётным периодам.

Модель также учитывает кадровые и организационные изменения, включая отдельные правила пересчёта при изменении руководящих позиций.

### Результат

Расчёт, который ранее требовал около **15–20 часов ручной работы ежемесячно**, полностью автоматизирован.

Сейчас модель:

- автоматически рассчитывает планы для **300–400 сотрудников**;
- использует **7 параметрических справочников**;
- получает данные из **2 автоматизированных кадровых источников**;
- автоматически учитывает изменения кадровых данных и периоды отсутствия;
- не требует ручного ежемесячного расчёта в Excel;
- передаёт результат в BI;
- автоматически пересчитывается и обновляется в BI каждое утро.

Сам SQL-расчёт выполняется примерно за **9 секунд**.

### Технологии

`SQL Server` `T-SQL` `CTE` `Window Functions` `JOIN` `CASE` `Aggregation` `Power BI`

## 02. Автоматизация управленческой отчётности по продажам

Автоматизация корпоративной управленческой отчётности, объединяющей данные по продажам, воронкам, прогнозам, дополнительным продуктам и другим бизнес-показателям.

Отчётность используется **500+ сотрудниками различных подразделений компании**, включая руководителей и топ-менеджмент.

### Задача

Изначально данные выгружались из корпоративных систем вручную, объединялись и обрабатывались в Excel.

Подготовка ежедневной отчётности занимала около **4–5 часов в день**.

Первым этапом процесс был автоматизирован с помощью VBA, что позволило сократить обработку примерно до **1–1,5 часов**.

Следующей задачей стала полная автоматизация процесса и перенос подготовки данных в SQL Server и BI.

### Решение

Был выстроен процесс подготовки управленческой аналитики:

```text
Корпоративные системы
        ↓
    SQL Server
        ↓
Подготовка и объединение данных
        ↓
Расчёт бизнес-показателей
        ↓
Аналитический слой
        ↓
    Power BI
        ↓
500+ пользователей
```

Для подключения необходимых данных я самостоятельно исследую доступные источники в корпоративных системах, определяю требуемые данные и показатели и формирую задачи для IT на их передачу в SQL Server.

После подключения источников выполняю дальнейшую обработку и объединение данных, реализую расчётные показатели и бизнес-правила.

В рамках решения реализованы:

- план-факт анализ продаж;
- консервативный и оптимистичный прогнозы;
- показатели нормативной и договорной ставки;
- количество заявок, отгрузок, договоров и клиентов;
- аналитика дополнительных продуктов;
- несколько вариантов воронки продаж и расчёт конверсий;
- аналитика приоритетных брендов с индивидуальными бизнес-правилами;
- анализ источников привлечения клиентов;
- аналитика по изъятой технике;
- финансовые и операционные показатели.

Консервативный и оптимистичный прогнозы рассчитываются в SQL на основании бизнес-логики и текущих данных.

Для отдельных направлений применяются собственные правила классификации и фильтрации. Например, условия включения сделки в конкретный аналитический блок могут зависеть от марки, типа и состояния транспортного средства и других бизнес-признаков.

В Power BI разработаны страницы отчётности, таблицы, фильтры, показатели и визуализации.

### Результат

Процесс, который первоначально требовал около **4–5 часов ручной работы ежедневно**, полностью автоматизирован.

Сейчас управленческая отчётность:

- используется более чем **500 сотрудниками**;
- доступна различным подразделениям и уровням управления;
- объединяет ключевые показатели в едином аналитическом решении;
- автоматически обновляется в BI **3 раза в день**;
- не требует ежедневной ручной выгрузки и обработки данных в Excel.

### Технологии

`SQL Server` `T-SQL` `CTE` `JOIN` `CASE` `UNION ALL` `Data Mapping` `Power BI` `Excel` `VBA`

## 💡 Подход к работе

В аналитических задачах не ограничиваюсь построением итогового отчёта.

Для новых задач сначала определяю бизнес-цель и необходимые показатели, исследую доступные источники данных и проверяю их качество. После этого формирую правила обработки и сопоставления данных, реализую расчётную логику и проверяю результат на контрольных выборках.

При автоматизации стараюсь отделять изменяемые бизнес-параметры от SQL-кода с помощью справочников и выстраивать решения так, чтобы изменения исходных данных автоматически учитывались при последующих пересчётах.
