# 🚀 Проекты

## 01. Автоматизация расчёта индивидуальных планов продаж

Разработка автоматизированной SQL-модели для расчёта ежемесячных индивидуальных планов продаж для **300–400 сотрудников**.

### Задача

Изначально расчёт выполнялся в Excel и занимал около **15–20 часов ежемесячно**.

Необходимо было перенести расчётную логику в SQL и автоматизировать процесс с учётом большого количества изменяющихся факторов:

- кадровых изменений;
- периодов отсутствия сотрудников;
- отпусков, больничных и других типов отсутствия;
- производственного календаря;
- количества рабочих дней;
- коэффициентов;
- организационных параметров;
- изменений руководящих позиций.

### Решение

Расчётная модель была перенесена из Excel в **SQL Server / T-SQL**.

Для автоматизации исходных данных были подключены кадровые выгрузки с информацией о сотрудниках и периодах их отсутствия.

Создано **7 справочников** с коэффициентами и другими изменяемыми параметрами расчёта.

Бизнес-параметры отделены от SQL-кода: изменение коэффициентов, сумм и других параметров выполняется через справочники и не требует изменения самого запроса.

Реализована логика обработки периодов отсутствия с использованием производственного календаря. Если отсутствие сотрудника приходится на несколько месяцев, рабочие дни автоматически распределяются между соответствующими периодами и учитываются при расчёте плана.

Также модель учитывает кадровые и организационные изменения, включая отдельную логику изменения плана при уходе руководителя.

### Результат

**До автоматизации:**

`15–20 часов ручной работы ежемесячно`

**После автоматизации:**

`~9 секунд на выполнение SQL-расчёта`

Дополнительно:

- расчёт выполняется для 300–400 сотрудников каждого месяца;
- используются 7 справочников с параметрами;
- подключены 2 автоматизированные кадровые выгрузки;
- существенно снижено количество ошибок;
- появилась возможность контролировать количество и причины отсутствий;
- изменения исходных кадровых данных учитываются при последующих пересчётах;
- результат перенесён в BI;
- BI автоматически обновляется каждое утро.
