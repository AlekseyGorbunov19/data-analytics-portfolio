# Автоматизация управленческой отчётности по продажам

> SQL Server · T-SQL · Power BI · Data Automation · Sales Analytics

## 📌 О проекте

Автоматизация ежедневной управленческой отчётности по продажам, используемой более чем 500 сотрудниками на разных уровнях компании — от сотрудников подразделений до руководителей.

Отчёт объединяет ключевые показатели различных направлений бизнеса и позволяет анализировать продажи, планы, прогнозы, воронку, дополнительные продукты, приоритетные бренды, каналы привлечения и другие показатели в едином BI-решении.

Изначально отчёт собирался вручную на основе выгрузок из корпоративных систем и требовал около 4–5 часов работы ежедневно.

Процесс автоматизации прошёл два этапа:

- на первом этапе обработка была автоматизирована с помощью VBA, что сократило время подготовки до 1–1,5 часов;
- на втором этапе необходимые данные были перенесены в SQL Server, бизнес-логика реализована на T-SQL, а итоговая отчётность перенесена в BI.

В текущей реализации ручная ежедневная сборка отчёта исключена, а данные автоматически обновляются 3 раза в день.


## 🎯 Задача

Основной задачей было отказаться от регулярной ручной обработки большого количества выгрузок и создать единый автоматизированный источник управленческой аналитики.

Решение должно было:

- объединять данные из различных корпоративных систем;
- автоматически рассчитывать ключевые показатели продаж;
- реализовывать бизнес-правила различных направлений;
- поддерживать анализ данных в разных разрезах;
- предоставлять единый свод показателей для сотрудников и руководителей;
- регулярно обновляться без ручной подготовки отчёта.


## 🔄 Этапы автоматизации

### 1. Ручная подготовка

Первоначально данные выгружались из корпоративных систем и вручную обрабатывались в Excel.

На подготовку ежедневной отчётности уходило около 4–5 часов.


### 2. Автоматизация с помощью VBA

На первом этапе значительная часть операций в Excel была автоматизирована с помощью VBA.

Это позволило сократить время подготовки отчёта до 1–1,5 часов, однако процесс по-прежнему зависел от выгрузки и обработки файлов.


### 3. Перенос логики в SQL Server и BI

Для полной автоматизации были определены необходимые исходные данные в корпоративных системах.

Для данных, которые требовалось подключить к аналитическому контуру, формировались задачи на интеграцию с участием IT.

После подключения источников данные обрабатывались в SQL Server: реализовывалась необходимая бизнес-логика, рассчитывались показатели и формировался аналитический слой для отчётности.

На основе подготовленных данных была самостоятельно построена BI-отчётность.

В результате ручная ежедневная сборка была исключена, а данные в BI обновляются автоматически 3 раза в день.


## 📊 Основные аналитические блоки

### 1. Управленческий свод

Основная страница содержит ключевые показатели продаж и позволяет быстро оценить текущее состояние бизнеса.

В отчёте представлены:

- план и факт продаж;
- консервативный прогноз;
- оптимистичный прогноз;
- средняя нормативная ставка;
- средняя контрактная ставка;
- количество заявок на лизинг;
- количество договоров лизинга;
- количество отгрузок;
- количество клиентов;
- другие операционные показатели.

Консервативный и оптимистичный прогнозы рассчитываются в SQL на основании бизнес-логики и актуальных данных.

Пользователь может изменять аналитический срез с помощью фильтров, включая период, тип техники, источник привлечения клиента и другие параметры.


### 2. Дополнительные продукты

Отдельный блок используется для анализа продаж дополнительных продуктов.

В модели учитывается около 10 видов дополнительных продуктов.

Для них рассчитываются:

- количество продаж;
- доля;
- конверсия относительно заявок на лизинг;
- конверсия относительно отгрузок.

Это позволяет оценивать не только абсолютный объём продаж дополнительных продуктов, но и их проникновение в основной процесс продаж.


### 3. Воронка продаж

Отдельная страница отображает движение клиентов и сделок по основным этапам процесса продаж.

Анализируются:

- обращения;
- заявки на лизинг;
- различные статусы заявок;
- договоры лизинга;
- отгрузки;
- конверсии между этапами.

Воронка представлена в нескольких вариантах: как последовательный переход между этапами процесса и как общий объём показателей за выбранный период.


### 4. Приоритетные бренды

Отдельный аналитический блок посвящён приоритетным брендам.

В отчётности анализируется около 15 приоритетных брендов.

Для каждого направления используются индивидуальные бизнес-правила отбора данных.

Например, принадлежность сделки к определённому приоритетному бренду может зависеть не только от марки техники, но и от:

- состояния техники;
- типа техники;
- принадлежности нескольких марок к одной группе;
- исключений отдельных категорий и моделей;
- дополнительных бизнес-условий.

Таким образом, классификация реализуется не простым фильтром по бренду, а набором отдельных бизнес-правил.

Для приоритетных брендов анализируются:

- план;
- факт;
- выполнение плана;
- количество заявок на лизинг;
- статусы заявок;
- другие связанные показатели.

Планы формируются другим подразделением и используются в аналитической модели для расчёта выполнения плана.


### 5. Каналы привлечения

Отдельный блок используется для анализа структуры продаж по источникам привлечения клиентов.

Для каждого канала рассчитывается его доля в общем объёме продаж.

Пользователь может дополнительно анализировать показатели в различных разрезах с помощью фильтров BI.


### 6. Изъятая техника

Отдельная страница предназначена для анализа реализации изъятой техники.

В ней представлены:

- количество лидов;
- распределение лидов по источникам привлечения;
- количество отгрузок в лизинг;
- денежные показатели реализации.

Для каждого аналитического блока в BI также используются графики и визуализации, дополняющие сводные таблицы.
